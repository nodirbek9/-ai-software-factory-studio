## What changed
1. **Payload (D-023).** `GET /api/projects/:id` drops `data.project` / `data.task` copies from history events
   (`slimHistoryEvent`). Real DB, largest project: 701 KB → 273 KB. Live SSE and `/api/v2/events` keep full data.
   Remaining large payloads: `/api/v2/events?limit=200` 258 KB (Logs, shows full event data on purpose),
   `/api/projects` 153 KB.
2. **Package install scripts (P7-S8, D-022).** Blocked by default per project: `--ignore-scripts` on installs,
   `npm_config_ignore_scripts` / `YARN_IGNORE_SCRIPTS` in the environment of every other command except explicit
   script runs (`npm test`, `npm run x`; their pre/post hooks still run), flags that switch scripts back on are refused.
   Project → Settings has *Allow scripts* (confirm dialog, `audit.install_scripts`).
3. **Owner terminals (Phase 3c, D-021).** Terminal tab in edit sessions: PowerShell (`-NoProfile`) in the session's own
   worktree via `@lydell/node-pty` + `@fastify/websocket` + xterm.js (lazy chunk). Loopback only, max 2 terminals and
   2 viewers each, killed after 15 minutes without owner input and before the session worktree or the project is
   removed; secrets stripped from env; audit events with the redacted transcript.

## Independent security review (GPT-6-Astra, read-only) — Opus verdicts
Report: `.ai-jobs/gpt-v21-terminal-review.log`.

| ID | Sev | Finding | Verdict |
|---|---|---|---|
| V21-S1 | CRITICAL | Absolute-form request targets (`GET http://host/api/x`) skipped all `/api/` hooks (Host, token, Origin) — **pre-existing since V1** | **Fixed**: any target not starting with `/` → 400. Test over a raw socket fails without the fix (200) |
| V21-S2 | CRITICAL | Tokenless loopback: another local process can open a terminal | **Accepted residual**: a process running as the owner can already start PowerShell itself; terminals add no capability to it. Other OS users on the PC or sandboxed agent CLIs with network access are the residual risk → set `ASF_AUTH_TOKEN` (terminals then need it too) |
| V21-S3 | HIGH | Install-script guard bypassable (`npx` implicit installs, path-qualified npm, `--ignore-scripts=false`) | **Fixed** (env-based block + override flags refused) |
| V21-S4 | MEDIUM | Terminal could reopen during discard/close; kill not awaited | **Fixed**: busy sessions refuse terminals; removal awaits shell exit (≤ 3 s) |
| V21-S5 | MEDIUM | Project delete left terminals running | **Fixed**: `beforeFilesRemoval` closes them first |
| V21-S6 | MEDIUM | `PGPASSWORD`, `DATABASE_URL` survived env stripping | **Fixed**: wider credential-name pattern (also for agent commands) |
| V21-S7 | MEDIUM | Unbounded viewers / buffered output | **Fixed**: 2 viewers, slow clients dropped at 1 MB buffered, sockets closed when the terminal ends |
| V21-S8 | MEDIUM | Shell profiles could change cwd or load credentials | **Fixed**: `-NoProfile` / `--noprofile --norc` |
| V21-S9 | MEDIUM | Output kept an unattended terminal alive | **Fixed**: only owner input resets the idle timer |
