## 1. Every-button audit
`e2e/audit.spec.ts` (Playwright on Edge, temp data, Scripted provider only — destructive buttons cannot touch real
data, confirm dialogs are dismissed). It seeds a finished scripted run and a workspace session, then on 15 pages
(all nav destinations, the project detail page and the V1 board / task graph / files pages) clicks every visible,
enabled button, tab and menu item, and after each click also every control that click revealed (one level deep:
tab panels, drawers, menus, dialogs). Any page error, console error or 5xx response fails the page.
Run it with `npx playwright test e2e/audit.spec.ts` (≈ 30 min).

Visual pass on the real studio (read-only: pages opened, nothing clicked): all pages render with real data.

## 2. Found and fixed
- **Header overlap** on narrower windows: the project picker spilled its text over the search box. The picker now
  shrinks and truncates (full name in its tooltip).
- **Studio stopped without a trace.** During the pass the 4317 studio was found stopped; Windows had no crash event,
  so it was a normal exit (closed window or Ctrl+C) — but nothing recorded why. The server now writes
  `data/logs/lifecycle.log`: start, stop reason (Ctrl+C, closed console window = SIGHUP, Ctrl+Break), uncaught errors
  with stack, exit code.

- **V2.2.1 — header at 1024 px.** After the first fix the picker shrank to 47 px on a 1024 px window and the header
  overflowed. The title text now shows from 1280 px, the agent/task counters and the progress bar from 1536 px; the
  picker keeps ≥ 7.5 rem. E2E checks the header fits at 1024/1280/1366/1920 px. The version number is now real
  (`2.2.1` instead of `0.1.0`).
- **V2.2.2 — blank page after an update.** A tab opened before an update asked for chunks of the old build; the server
  answered with the HTML page, the module failed on its MIME type and the screen stayed dark until a manual reload.
  Missing `/assets/*` are now 404, and the dashboard reloads itself once (at most once a minute) when a page chunk
  cannot be loaded. E2E simulates it.
